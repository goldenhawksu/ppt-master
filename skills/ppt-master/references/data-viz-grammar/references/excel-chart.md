# Excel 图表 —— 规则版落地

> Excel 的天花板不在图种，而在默认装饰：3D、阴影、彩色图例、粗边框。
> 让 Excel 出“报表级”图的成本很低，关键是把默认项全部关掉。

## 1. 按意图选图种（Excel 里真能做的）

| 意图 | Excel 图种 | 设置要点 |
|---|---|---|
| 偏离 | 簇状条形 + 轴交叉于 0 | 负值填负向色；零线加粗 1px |
| 排名 | 条形图（**降序**，横向） | `逆序类别` 让最大值在顶部 |
| 分布 | 直方图 / 箱线图 | 组距固定（如 0.5 天），柱间隙宽 0% |
| 时序 | 折线 | 标记点关闭；只保留横向网格线 |
| 构成 | 100% 堆叠柱 | 段数 ≤5；段内直接标 %（数据标签） |
| 量级 | 条形（非 3D） | 差 >10 倍改用比例符号（需手画圆） |
| 相关 | 散点 | 加趋势线（仅当 r² 值得说） |
| 流向 | waterfall（Excel 2016+） | 总计柱必须与起点/终点闭合 |

饼图只在一对一构成且段数 ≤4 时可用；时序、排名、对比一律不用。

## 2. 必关的默认项（逐项清单）

- [ ] 图表区填充：无（白底），边框：无
- [ ] 绘图区填充：无，边框：无
- [ ] 网格线：只留主横线（浅灰 `#DAD7D0`），删除纵线与次网格
- [ ] 坐标轴：Y 轴线与刻度线删除，只留标签；X 轴线保留 1px 浅灰
- [ ] 图例：系列 ≤4 时删除，改用数据标签或直接写在系列末端
- [ ] 阴影 / 3D / 渐变 / 图片填充：全部禁止
- [ ] 字体：统一 `微软雅黑`，标题 12pt（图内）/正文 10pt，**下限 10pt**
- [ ] 数字格式：千分位 + 单位只出现一次（写在轴名或标题）

## 3. 结论式标题

Excel 图标题默认是“系列名”，必须改成**结论句**：
- ✗ `COPQ 趋势`
- ✓ `7 月起 COPQ 连续 3 月高于目标，累计超 42 万元`

把口径放副标题或单元格注释：`数据来源：工时明细 ｜ 口径：能源费用=人工成本（去物料）`。

## 4. 条件格式 = 色阶，不是装饰

- 只用**单色阶**（白 → `#2C5C7E`），不要用红绿双色阶（文化歧义 + 有序数据用色相）
- 数据条仅用于同一列内比较，且隐藏数值（否则双编码）
- 图标集（↑↓）只用于“变化方向”列，不用于绝对量

## 5. 出图给 PPT/HTML 用

优先**不要截图**：Excel → `复制为图片` 会丢清晰度。两条路：
1. `图表 → 另存为图片 (PNG)`，并在页面设置里把图表尺寸设到目标英寸（避免放大模糊）。
2. 直接重画为 SVG（`ppt-master` 模板或 matplotlib）—— 需要可编辑/需嵌入品牌版式时用这条。

## 6. 交付前 4 条

1. 标题能读成一句结论（含数字或方向词）。
2. 有无来源行（写在图下方单元格或脚注）。
3. 强调色只有一种；其余灰阶。
4. 打印预览：字号是否 ≥10pt、有无被裁切。
