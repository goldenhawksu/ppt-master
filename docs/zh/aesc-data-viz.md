## 2. 工作区与原型

工作区根：`skills/ppt-master/templates/decks/aesc_ppt_data_viz/`。
主规范：`templates/design_spec.md`；第 VIII 节是 AESC 图表适配规则的唯一维护位置。
画布 1280×720，单 AESC Master，白色正文、照片封面和深色照片结束页。
面向 CTS、质量、成本、售后物流及海外业务管理汇报，支持现场讲述和会后阅读。

| 原型 | 用途与主要内容槽 |
| --- | --- |
| `01_cover.svg` | 封面：标题、副标题、汇报人、日期 |
| `02_toc.svg` | 目录：标题、四组章节标题与说明 |
| `03_chapter.svg` | 章节：编号、标题、副标题 |
| `04_content.svg` | 通用正文：结论标题、关键信息、可编辑内容区 |
| `04a_chart_insight.svg` | 图表洞察：原生排名条形图、结论、证据、行动 |
| `04b_comparison_swing.svg` | 前后对比：基线/方案内容区、比较结论 |
| `04c_hero_number.svg` | 核心指标：大数、基线、含义、原生趋势图 |
| `04d_bridge_waterfall.svg` | 归因桥：原生瀑布图、归因结论 |
| `04e_table_with_trend.svg` | 明细趋势：原生表格、原生折线图、说明、行动 |
| `05_ending.svg` | 结束：致谢、联系信息、日期 |

图表中的数值和期间均为演示数据，不是 AESC 业务事实。原型不是未来报告的固定页数或必选章节。
支持的图表优先使用原生 PowerPoint 图表及嵌入数据；超出原生接口的图种使用可编辑矢量。
类型化图表/表格槽保持原类型，不能为容纳自定义图形而悄悄改成普通对象槽。

## 3. 图表能力与检查

- 独立 ZIP 的五个文件保存于 `skills/ppt-master/references/data-viz-grammar/`，保留作者、许可和版本。
- 仅规范化换行，逐个与 ZIP 原文核对；原包哈希和来源见脚本文档第 4 节。
- 当前真实图表目录有 **33 个键**，不宣称装入了安装说明中的 95 图表整包。
- Default 规划/执行与 Quick 活动上下文均在选中模板后按需加载，不加入所有任务常驻上下文。
- 优先结论驱动的证据图表；缺失值不自动补零，红色仅表达风险，不把成本降低机械标红。
- `check_aesc_viz.py` 补查意图、目录键、可见结论/来源及可编辑图元；原有 Verify Charts、原生载荷和最终 SVG 门禁仍需执行。

审计命令（替换项目绝对路径）：

```powershell
& 'C:\github-repo\ppt-master\.venv\Scripts\python.exe' 'C:\github-repo\ppt-master\skills\ppt-master\scripts\check_aesc_viz.py' '<项目绝对路径>' --require-charts --json
```

此检查只读，**不是导出器自动强制门禁**，也不证明事实真实性、图种适配、几何正确或全量可视化覆盖率。
规范原型故意保留占位符，不能拿它们冒充已经填完的证据页；应审计实际填充的页面。
