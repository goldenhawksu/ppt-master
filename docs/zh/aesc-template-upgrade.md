## 2. 页面与保留内容

新系统采用 1280×720 画布、一个 AESC Master、五个 Layout 和 33 个可编辑文本/内容占位符。
五个原型均为新建的完整 SVG，不是向旧文件补写 Master/Layout 字段。

| 原型 | 角色与主要槽位 |
| --- | --- |
| `01_cover.svg` | 封面：品牌、标题、副标题、汇报人、日期，共 5 槽 |
| `02_toc.svg` | 目录：品牌、页码、目录标题、五组章节标题/说明，共 13 槽 |
| `03_chapter.svg` | 章节：品牌、页码、编号、标题、说明，共 5 槽 |
| `04_content.svg` | 正文：品牌、页码、结论标题、关键信息、证据内容区、来源，共 6 槽 |
| `05_ending.svg` | 结束：致谢、品牌、联系方式、日期，共 4 槽 |

保留原版的蓝灰品牌体系、双语字体栈、四区页眉、五项目录、章节长竖线和灵活正文区。
封面图与结束图均为原件字节复制。**封面不加遮罩、渐变、滤镜或局部压暗**，
只保留原有展示区域与居中等比铺放，不对图片本身进行处理。

原型复核中的调整：

- 去掉旧封面的压暗渐变，落实用户已确认的不加工原图要求。
- 把正文示意占位文字改为左上开始的完整内容槽，不把居中的设计指南当作正式内容。
- 移除正文重复页码，只保留页眉页码。
- PowerPoint 首次测量发现右对齐页码有 2.75 磅外溢；恢复原版 x = 1200 的居中位置后复测，无文字越界。

这些是五类基础原型，不规定未来报告页数和章节。旧规范中的六章汇报示例仅作场景参考，
不转成每次生成必须包含的章节。没有复制数据洞察版的十页原型，也没有捏造演示业务数据。

## 3. 图表与规则接入

基础版保留图表优先的证据表达入口、语义红和 ThinkCell 风格甘特图偏好。
新规范第 VIII 节指向 `aesc_ppt_data_viz` 规范第 VIII 节这一唯一 AESC 图表适配规则位置，
由该位置按需加载仓库内的 data-viz-grammar。不会复制成第二套容易漂移的规则。

提示词审计清单新增独立可选加载集 `stage.generate.template.aesc`，记录基础规范及必要引用。
它只用于审计，不是运行时加载器；实际加载由选中模板后的规范入口触发，没有增加全局常驻上下文。

基础原型没有示例图表载荷。真实数据页仍须按实际论点选择图表，执行补充审计、Verify Charts
和最终 SVG 门禁。不得把“模板五页通过”理解为未来业务数据与图表已经通过验证。
